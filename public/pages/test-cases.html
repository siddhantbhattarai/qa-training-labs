📝 Test Case Templates

Learn professional test case documentation with these templates and examples

💡 Tip: Good test cases are clear, concise, and repeatable. Anyone should be able to execute them and get the same results.

📋 Standard Test Case Template

Field Description Example
Test Case ID Unique identifier for the test case TC-AUTH-001
Title Brief description of what is being tested Verify user login with valid credentials
Module Feature or component being tested Authentication
Priority High, Medium, or Low High
Preconditions Requirements before test execution User account exists, database seeded
Test Steps Numbered steps to execute the test 1. Navigate to login page
2. Enter email
3. Enter password
4. Click Login
Test Data Specific data used for testing Email: admin@qalab.com
Password: Admin@1234
Expected Result What should happen if test passes User is redirected to dashboard, welcome message shown
Actual Result What actually happened (filled during execution) User redirected to dashboard successfully
Status Pass, Fail, or Blocked PASS
Comments Additional notes or observations Response time: 450ms

🐛 Bug Report Template

Professional Bug Report Format

Field Example
Bug ID BUG-001
Title Negative quantity accepted when adding items to cart
Severity High (Critical / High / Medium / Low)
Priority P1 (P1 / P2 / P3 / P4)
Environment Production - https://qa-training-labs.onrender.com
Browser: Chrome 120
OS: Windows 11
Steps to Reproduce 1. Login as any user
2. Open Postman or API client
3. POST to /api/cart/add with body: {"productId": "valid_id", "quantity": -5}
4. Include Authorization: Bearer token
5. Send request
Expected Result API should return 400 Bad Request with message "Quantity must be positive"
Actual Result API returns 200 OK and adds item with negative quantity. Cart total becomes negative.
Screenshot/Evidence [Attach Postman screenshot showing the response]
Impact Users could exploit this to get negative cart totals, potentially leading to financial issues
Suggested Fix Add validation in /api/cart/add to check quantity > 0 before adding to cart
